# Frontend Developer Portfolio (Dark Futuristic)

This is a single-page, mobile-first portfolio built with HTML, CSS, JavaScript and GSAP.

Features
- Dark futuristic theme with glassmorphism UI
- Fully responsive (mobile-first)
- GSAP-powered animations with ScrollTrigger
- Typing effect, floating blobs, magnetic buttons, cursor glow
- Lazy-loaded images and performance considerations

File structure

portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images/ (place your images here)
│   └── icons/ (optional SVG icons)
└── README.md

Usage
1. Open `index.html` in a browser.
2. Replace placeholder images in `assets/images` with optimized images (webp recommended).

Performance notes
- Use optimized images (WebP) and serve from CDN where possible.
- Remove unused fonts or subset them for production.
- Consider inlining critical CSS for fastest paint.
